# PlaneByte AI-first journeys

1. **Understand current workspace:** Home → type a question → open assistant draft → explicitly Send. Counts and usage use authorized deterministic reads, create no AI job and consume no provider request. Private conversation history is retained server-side and scoped by actor/workspace.
2. **Describe a search:** Discover → describe a customer problem → Generate criteria → review/edit → explicitly Search. Source permissions, bounded limits and quota checks remain server-enforced. A manual fallback is labeled when AI drafting is unavailable.
3. **Refine business context:** Intelligence Graph → choose a category → edit → Save → reload. Shared context updates future context reads; historical research snapshots and monitor criteria are preserved.
4. **Review evidence:** Signals → keep filters → select a title or Review → inspect original quote, uncertainty and explanation in a drawer → save/review/dismiss or add an eligible opportunity. Close returns to the same list state. No contact or message is created.
5. **Monitor:** Create a reviewed draft → explicitly activate/configure supported schedule or run a manual bounded check → inspect run history and alerts. No monitor is activated by a graph edit or assistant question.
6. **Research:** Growth tabs → ask a question against collected authorized evidence → background status/cancellation → inspect citations/limits → save/export a completed current snapshot.
7. **Manage access:** Settings → Account, Company, Team, Security or Developer. Existing role checks, revision checks and Google-only sign-in apply. No password-changing or pretend invitation action is added.
8. **Understand capacity:** Usage & Billing → current access and remaining allowance → optional approved plan comparison. PayU recurring checkout stays gated pending merchant verification; no money moves during these journeys.

Browser fixtures validate mechanics; genuine production worker/provider acceptance and independent human quality review are separate evidence gates.
