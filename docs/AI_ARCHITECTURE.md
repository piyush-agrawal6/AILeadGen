# AI architecture

Preserve the existing Vertex-first provider gateway and configured fallbacks. Product modules must reuse that boundary for structured extraction, classification and assistance, rather than introducing separate model clients.

External website/email text is untrusted data. Use bounded inputs, schema validation, safe retries and deterministic critical paths. Never execute generated SQL/code or invent metrics/findings. Keep credentials and private histories out of prompts/logs and meter real usage by workspace before public availability.

The former five-day copy experiment is not the default HeySow email workflow. A comprehensive HeySow AI Agent, agent entitlements and agent tooling remain planned; the module registry explicitly marks the Agent unavailable.
